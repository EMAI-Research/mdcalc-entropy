# Public reproducibility release plan

Release the reviewed BMJ 0.14.3 analysis materials as code package 0.2.0.

- Publish the final analysis and figure scripts, pinned dependencies, de-identified derived CSV files, result summaries, data dictionary, and scoped licences.
- Exclude the source workbook, manuscript and submission files, author information, generated figure binaries, and internal figure-selection notes.
- Verify hashes and expected result counts, scan for secrets and unsafe Python patterns, commit and tag the release, then make the EMAI repository public.
